# YaMousahil — Islamic App (HTML / CSS / JavaScript)

Application islamique interactive : horaires de prière, القرآن الكريم,
الأذكار, مسبحة إلكترونية, أسماء الله الحسنى, بث مباشر, مساجد قريبة.

## Lancement local

```bash
node serve.js          # serveur http://localhost:8765
```

Ou ouvrir `index.html` directement (les flux vidéo YouTube exigent `http`).

## Déploiement GitHub Pages

1. Créer un dépôt **Public** sur GitHub.
2. Pousser le contenu `main` (fichiers à la racine).
3. **Settings → Pages → Deploy from branch → `main` / `/ (root)`**.
4. Site publié sur `https://<utilisateur>.github.io/<dépôt>/`.

Les images locales sont dans `assets/img/`, le logo racine `Logo.png`.
